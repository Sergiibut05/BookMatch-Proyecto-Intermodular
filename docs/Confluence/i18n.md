# i18n

### Implementación

**@ngx-translate/core** (y loader HTTP si está configurado en `app.config.ts`) para cadenas en **es** y **en**.

### Ficheros

* `src/assets/i18n/es.json`
* `src/assets/i18n/en.json`

### Comportamiento habitual

1. Preferencia guardada (p. ej. `localStorage`) si existe.
2. Si no, idioma del navegador.
3. Fallback a **es** si el idioma no está soportado.

_(El flujo exacto está en_ `TranslationService` / inicialización de la app.)

### Uso en plantillas

<!\[CDATA\[{{ 'clave.subclave' | translate }}\]\]>

### Uso en TypeScript

<!\[CDATA\[this.translate.get('clave.subclave').subscribe(text => { ... });\]\]>

### Cambiar idioma

Desde el selector de idioma o llamando al servicio de traducción que exponga `setLanguage('en' | 'es')`.
